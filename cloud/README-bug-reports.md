# 手机问题反馈

入口：题目弹窗“反馈此题”、更多菜单和页脚“反馈问题”。管理入口为 `#feedback`，只允许已验证且 `app_metadata.cquest_role=admin` 的站点管理员查看、标记已处理或重开。

先在已有 Supabase 项目运行 `bug-reports.sql`，再发布前端。表启用并强制 RLS，普通用户和游客没有直接读写权限，只能通过固定 RPC 提交；管理员身份由数据库中的应用元数据核对，不信任客户端或用户自行修改的元数据。

允许匿名反馈，以便登录／注册出错时仍可报告。服务端限制：每个已登录账号每天10条，匿名总量每小时30条，全站每天200条，总存储5000条。限制用于约束免费资源消耗，不能代替验证码或完整的防滥用系统。超过限制不自动重试。

反馈编号用于失败重试去重。正文10—2000字；环境信息仅含页面名称、题号、模式、题目位置、屏幕尺寸和浏览器类型。不会自动收集邮箱、完整URL、完整UA、学习草稿、答案或密钥。用户可取消附带环境信息。

离线草稿仅保存在 `cquest-bug-draft-v1`，只含正文、类别、反馈编号；成功后清除此独立键，不影响学习进度。可以复制反馈文字自行发送。当前版本没有截图上传和后台自动抓取日志。

验证：

```
node tools/test_bug_report_sql.mjs
node tools/test_bug_report_account.cjs
node tools/test_bug_report_ui.cjs
node tools/test_quiz_next.cjs
```

SQL测试使用现有隔离 PGlite。UI测试使用独立浏览器上下文和模拟请求，不操作真实账号。
